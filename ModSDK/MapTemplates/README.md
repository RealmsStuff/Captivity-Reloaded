# Map templates

`TiledStage` is the no-Unity starter kit for finite orthogonal Tiled JSON maps. It includes editable visual layers, collision platforms, navigation links, a player start, enemy spawners, audio, moving platforms, particles, pickups, doors, vendors, cases, lights, interactions, and a small stage-script example.

Start with [TiledStage/README.md](TiledStage/README.md) for the supported map settings, object table, validation commands, and test workflow. The authored-map contract is still experimental, so use the supplied templates and schemas rather than inventing fields.
