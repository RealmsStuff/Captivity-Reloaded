# Core combat-stage platform bounds

Approximate bounds measured from Platform-layer `BoxCollider2D` components in the Core stage prefabs. These describe authored playable collision, not background artwork or camera framing.

| Stage | Width | Height |
| --- | ---: | ---: |
| Space Station | 256.8 | 11.0 |
| Field-Day | 158.1 | 17.8 |
| Shack | 158.1 | 18.2 |
| Jungle | 177.5 | 27.5 |
| Furry Entertainment Robotics | 222.2 | 47.8 |
| Cave | 205.6 | 82.6 |

Space Station is the widest combat stage and Cave has the greatest vertical span. The starter canvas is therefore 256 by 96 Unity units/tiles at 32 pixels per unit. Hub is excluded because it is not a wave-combat stage.
