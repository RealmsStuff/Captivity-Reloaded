# Captivity Reloaded 2.2.2 — Patch Notes

Version 2.2.2 adds a native Randomizer mode, keyboard-only combat support, and several interface and weapon fixes.

## Randomizer mode

- Added Randomizer as a built-in game mode that works without mods.
- Each combat-stage run grants a constrained random loadout of two or three unique Core weapons.
- Random loadouts respect the normal inventory weight limit and exclude developer, Special, mod-added, and Schockgewehr weapons.
- Randomizer weapons begin fully loaded and remain locked until the run ends.
- Buying, selling, dropping, and collecting replacement guns is disabled while the loadout is locked.
- Wall-mounted weapon purchases and their prompts are hidden during Randomizer runs.
- Ammunition purchases, consumables, clothing, keys, and other non-weapon items continue to work normally.
- Returning to the Hub clears the Randomizer status and the next combat run rolls a new loadout.

## Keyboard-only controls

- Added assisted targeting when both Fire and Reload are assigned to keyboard keys.
- Keyboard-only aiming selects the closest valid hostile in the player's chosen direction.
- Mouse movement no longer changes aim while keyboard-only aiming is active.
- Double-tap the left or right movement key to turn and aim in that direction.
- Controller, touch, and ordinary mouse aiming retain their existing behavior.

## Gameplay and interface fixes

- Removed Schockgewehr from normal weapon vendors while preserving its intended secret-stage pickup.
- Centered the location choices within the location menu.
- Restored and stabilized the location information panel and scrollbar.
- Kept the title update banner centered beneath the logo and within its background at supported aspect ratios.
- Increased the update banner controls for easier touch input.

## Included compatibility work

- Added optional player-attachment climax emitters.
- Updated the included futanari and femboy example packs to use the appropriate emitter.
- Existing Mod API v1 packs remain compatible.
