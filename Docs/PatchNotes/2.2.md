# Captivity Reloaded 2.2 — Patch Notes

Released October 11, 2026. These notes cover changes since version 2.1.2.

Version 2.2 is primarily a modding, authoring, and stability release. Existing Mod API v1 packs remain compatible; the newly added fields and systems are optional.

## Highlights

- Added support for phased finishers containing up to three independent secondary NPCs.
- Secondary NPCs can be present from the start or join an open participant slot at a later phase boundary.
- Added cursed-clothing effects that can change escape strength and enemy bounty rewards.
- Enemies can now force-equip clothing through attacks or finisher outcomes.
- Mod changes can be activated from the Mods panel with **Apply Mods**, without restarting the entire game.
- Added a complete public catalog of Core enemy sprite-replacement slots.
- Added one-click DragonBones export for every Core enemy and its animations.

## Gameplay and interface

- The optional **Self Pleasure** input is now hidden from the controls screen unless an active mod enables that mechanic. Standard mode no longer presents a nonfunctional `M` binding.
- Fixed knockout and exhausted-state recovery when using a controller. Controller players now use the mapped jump action instead of directional axes that could not register the required alternating presses.
- Improved recovery input and prompts on mobile controls.
- Fixed controller and mobile rotation QTEs rejecting fast circular input or resetting when the stick briefly crossed its center. A recognized circle now contributes the same progress as four alternating inputs.
- Fixed Android mobile controls masking a connected physical controller during rotation QTEs. When a gamepad was used last, its right stick and matching prompt now take priority over the on-screen aim stick.
- Large money balances now resize to remain readable instead of wrapping or being cut off.
- Improved startup safety when player rule modifiers are initialized before every player component is ready.
- Updated the title-screen version display for release 2.2.

## Mod management

- Installing, updating, enabling, disabling, rolling back, or uninstalling a mod now changes the Mods panel button to **Apply Mods**.
- Applying changes reloads the title scene and rebuilds modded runtime content. A complete game restart is no longer required for these operations.
- Corrected catalog integrity information for C4C, Clothing + Shack Overhaul, Luin's Balance Mod, and Overpower so their downloads pass package verification.
- Removed the duplicate source copy of the Captivity SFW example. The catalog-distributed version remains the canonical package.

## Enemy and finisher modding

- Added multi-participant phased finishers with configurable participant slots, shared-frame offsets, facing, approach distance, join distance, and entry policy.
- Late-arriving enemies can reserve an open slot, approach the interaction, and synchronize at a phase boundary.
- Participant AI, attacks, physics, collision, position, facing, animation, and sorting state are restored when the interaction ends.
- Added per-phase participant animation mappings.
- Added adaptive, alternate, rotate, and tap QTE input patterns with device-appropriate prompts.
- Improved paired finisher alignment and draw order during playback.
- The paired-finisher authoring tool now reads existing timing and preserves phases three and later unless the author explicitly replaces the complete phase list.
- Improved cleanup and state restoration when a modular finisher ends or is interrupted.

## Clothing and rule-profile modding

- Added `escapePowerMultiplier` and `bountyMultiplier` clothing effects.
- Added the `onHitEquipClothing` enemy behavior, including chance and cooldown controls.
- Finisher success and failure outcomes can now equip one or more clothing definitions.
- Forced clothing follows the normal compatibility rules, is persisted and unlocked, and can still be removed from the wardrobe.
- Added fully original atlas-authored clothing with custom `piece/...` regions.
- Added configurable idle amplitude and frequency for procedural clothing sway.
- Added pack-activated rule profiles. These apply automatically while their pack is loaded without appearing as a selectable game mode.

## Asset replacement and authoring tools

- Published the complete Core enemy asset-slot catalog, including animated and anatomy-specific sprite slots that were previously difficult to discover.
- Expanded runtime binding so animated enemy sprite replacements apply consistently across relevant animation states.
- Added batch DragonBones export for every Core enemy, including normalized rigs, animations, images, round-trip metadata, and an export index.
- Expanded the Unity enemy wizard and DragonBones round-trip workflow for paired and multi-participant interactions.
- Added an authored-hairstyle example demonstrating atlas pieces and idle movement.

## Documentation

- Reorganized the mod-development guide into a complete wiki-style reference.
- Added field-by-field API pages, a searchable validation/error-code catalog, public asset-slot catalogs, installation instructions, screenshots, examples, and platform guidance.
- Added documented workflows for Unity authoring tools, Tiled, DragonBones, packaging, catalog publishing, testing, and contribution review.

## Compatibility and verification

- Existing Mod API v1 packs continue to use their previous behavior when the new optional fields are omitted.
- Release builds were produced for Windows, Android, and WebGL.
- Final verification passed 336 EditMode tests, 13 PlayMode tests, and validation of 490 example documents.
