# Captivity Reloaded 2.2.3 — Patch Notes

Version 2.2.3 expands animation modding, adds authored special waves and character-reference exports, and includes gameplay, interface, and clothing fixes.

## Animation and enemy modding

- Added Core-enemy animation replacement and additional-animation support.
- Added multiple finishers per enemy and extra attacks for Core enemy variants.
- Added per-attack miss animations, knockdown timing, animation blend timing, and finisher contact controls.
- Added finisher start freezes, Core-style grab reactions, escape-window phase controls, and pack-authored player effects.
- Fixed long enemy clips being discarded and clips continuing after their own events start another clip.
- Fixed the finisher phase blend setting after the earlier attachment-system merge.
- Shipped the Core animation reference with standalone builds and expanded the DragonBones export to enemies, reference NPCs, and the player.

## Waves, stages, and gameplay

- Added the recommended Core special-wave roster, including the Faceless Mannequin spotlight wave with Abby.
- Added special-wave signal triggers, HUD announcements, and active-wave names.
- Allowed original enemies to join compatible Core stage spawners.
- Fixed climbing enemies skipping intermediate ledges when another climber was nearby.
- Preserved normal wave progression after a special wave ends.

## Player, interface, and clothing fixes

- Restored the base-game brown ponytail as a two-piece hairstyle with bounded movement sway.
- Added validated sway physics support for Core clothing pieces.
- Fixed the title background jumping during its loop.
- Included the Android touch-control visibility fix and complete character-export support.

## Compatibility

- Existing Mod API v1 packs remain compatible.
- Packs using the new Core-animation and finisher fields require game version 2.2.3 or later.
