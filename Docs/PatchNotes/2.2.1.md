# Captivity Reloaded 2.2.1 — Patch Notes

Version 2.2.1 is a compatibility patch for enemy appearance mods.

## Fixes

- Completed the public Core visual replacement catalog for interface, environment, effect, prop, and character artwork.
- Published 417 enemy-specific renderer slots across all 21 Core enemies, plus 72 compatibility aliases.
- Added isolated multipart slots for enemies with separate foot-base, foot-end, breast, breast-background, and anatomy artwork.
- Fixed Jenny retextures requiring shared global sprite replacements for multipart feet and breasts.
- Kept enemy-specific replacements isolated when multiple enemies reuse the same original sprite name.
- Added runtime diagnostics for unavailable legacy sprite baselines.

## Mod compatibility

- Existing Mod API v1 packs remain compatible.
- Enemy retextures should prefer `core:enemy/<enemy>/...` IDs over shared `core:sprite/...` compatibility IDs.
- The public catalog now contains 1,544 exact slot IDs and links to the detailed per-enemy rig catalog.
