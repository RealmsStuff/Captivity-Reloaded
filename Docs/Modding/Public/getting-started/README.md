# Getting started

A Captivity Reloaded mod is a folder containing a `manifest.json`, one or more JSON content definitions, and optional assets. Data-only packs cannot load arbitrary scripts or assemblies.

Choose the path that matches what you are trying to do:

- To play with community content, use [Installing mods](installing-mods.md).
- To package or verify a cross-platform mod, read [Windows, Android, and WebGL](platforms.md).
- To make a small data-only mod, follow [Your first pack](first-pack.md).
- To turn a validated source folder into an installable archive, use [Packaging a `.capmod`](packaging.md).
- To share a finished pack, use [Publishing to the community catalog](publishing-to-catalog.md).
- To change the game or its editor tooling, begin with [Development setup](../development/setup.md).

Mod authors should copy the closest pack from the [example index](../reference/example-packs.md), keep its directory layout, change its namespace and IDs, and validate after every small change. Do not begin with an advanced animation or stage example unless the mod actually needs those systems.
