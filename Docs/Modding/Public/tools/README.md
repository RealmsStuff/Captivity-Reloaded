# Authoring tools

The SDK favors free tools with open formats. LibreSprite is used for pixel-art templates, Tiled JSON is used for the experimental authored-map pipeline, and DragonBones is the optional external bone-animation editor. These tools may be installed outside the workspace; their project files and exported game assets stay inside the mod project. Captivity converts DragonBones JSON back into its own portable animation format and does not require the DragonBones runtime in the game.
