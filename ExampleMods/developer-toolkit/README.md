# Captivity Multi-Tool

Enable this pack to make its tool panel available. Select **Captivity Multi-Tool** from the game-mode selector when you also want the original mod's C4C-derived gameplay rules. The conversion restores its developer menu without copying its unsafe hard-coded assumptions.

Press `F1` or use the **Tools** button in the upper-left corner during gameplay. The responsive panel provides:

- money, heart, health, libido, pleasure, strength, orgasm, pregnancy, and hypnosis actions;
- infinite ammunition, no reload, infinite strength, and infinite stamina toggles;
- selectable registered Core and modded weapons;
- selectable registered Core and modded enemies, with normal, pregnancy, ragdoll, and no-thinking actions;
- wave-intermission adjustment in 30-second steps;
- direct travel to every registered stage.

Completing every challenge and unlocking every clothing item alter the active save and therefore require an explicit confirmation. Tool actions remain available while the CMT pack is enabled; the selected game mode controls only its C4C-derived rules.
