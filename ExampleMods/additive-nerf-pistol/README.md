# Additive Nerf Pistol example

This disabled example converts @SomeScrub's legacy starter-pistol artwork into a separate data-driven weapon. It extends `core:item/weapon/pistol`, so firing behavior, animation, audio, ammunition, and statistics are inherited while the original Core pistol remains available.

Copy this entire directory into the project-level `Mods` directory, or into `Mods` beside a built game, to enable it.
