# Extended Difficulties

Data-driven conversion of @DakoZan's original 1.0.5b DLL mod. It adds Very Hard and Nightmare to the existing difficulty selector without replacing `Assembly-CSharp.dll`.

- Very Hard: 150% enemy health, 125% player damage taken, 50% escape strength.
- Nightmare: 150% enemy health, 150% player damage taken, 25% escape strength.
