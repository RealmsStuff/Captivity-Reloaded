# Convenience Mechanics

This optional rule-profile mod enables three mechanics that are disabled in Standard mode:

- Self-pleasure during active waves with `M`, View/Share, or the mobile Pleasure button. It fills pleasure without costing a heart and uses the late Squoid player loop.
- Repeat purchases of consumables while retaining the normal six-item inventory limit.
- An outfit-repair button at vendors that restores missing pieces of the equipped clothing.

Install or enable the pack, restart the game, and select **Convenience Mechanics** under **Options > Game mode**. Selecting Standard disables all three mechanics.
