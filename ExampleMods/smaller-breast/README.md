# Smaller Breast

Faithful `.capmod` source conversion of the legacy **Smaller Breast Mod**.

The original archive was compared sprite-by-sprite with Captivity v1.0.5b. This package preserves all 35 deliberate artwork edits:

- four player chest skin palettes;
- 28 affected Core clothing chest/icon/spine source sprites;
- Betsy's chest and the placed `Chest_7` character sprite;
- Jenny's `Butt_6` sprite used by her paired presentation.

Five atlas records whose decoded pixels differed only by texture-compression noise were intentionally excluded: `Hair2`, `StockingPunkUpper`, `StockingPunkLower`, `SecuritySpine`, and the 250×250 application icon. They contain no authored visual change.
