# Smaller Breast and Butt

Faithful `.capmod` source conversion of the legacy **Smaller Breast and Butt Mod**.

The combined archive contains the exact Smaller Breast artwork plus 17 deliberate butt edits. To avoid duplicating identical files, this package depends on `legacy.smaller-breast` and contributes:

- four player butt skin palettes;
- the shared Zombie 1/3 butt and Zombie 2 butt;
- the FER placed `Butt_5` sprite;
- ten lower-garment sprite sources distributed across twelve Core clothing targets.
