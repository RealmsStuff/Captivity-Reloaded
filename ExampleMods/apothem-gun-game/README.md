# Apothem Gun Game

A data-only conversion of **Gun Game v2** by the.apothem (Zachary).

Enable the pack, then choose **Gun Game** from **Options > Game mode**. Selecting **Standard** disables mode rules without disabling the content pack.

The player starts each combat stage with the Core pistol. Every enemy kill removes existing guns and grants one random gun from the original 21-weapon pool. Medicines, keys, money, and other non-weapon inventory items are preserved.

Change `selection` to `ordered` to cycle through the declared pool instead of choosing randomly.
