# FutaZombies

Faithful `.capmod` source conversion of the legacy **FutaZombies** archive.

The original archive replaces the existing Zombie I, Zombie II, and Zombie III artwork. It does not add new enemies or alter their AI, stats, spawning, animation clips, or gameplay. This conversion therefore patches the three shipped Core rigs through semantic body slots rather than registering duplicate enemy variants.

The archive contains 40 deliberate sprite edits: fourteen for Zombie I, thirteen for Zombie II, and thirteen for Zombie III. Zombie II and III each share one authored foot sprite between the left and right rig slots, producing 42 runtime slot assignments from those 40 source images. No compression-only records were found.

The source archive contains no author or version text, so its author is recorded as the legacy mod author rather than inventing attribution.
