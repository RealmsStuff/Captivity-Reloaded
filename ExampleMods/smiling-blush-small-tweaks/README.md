# Smiling Blush + Small Tweaks conversion

The supplied archive contains the complete **Small Tweaks** sprite set plus twelve changed player-mouth sprites. This conversion expresses that relationship directly: install `legacy.small-tweaks` automatically, then apply only the smiling mouth artwork unique to this pack.

Keeping the shared portion as a dependency prevents duplicate files and unresolved asset-patch conflicts. No gameplay behavior has been invented.

The supplied copy does not identify its original author or redistribution license, so provenance remains unresolved.
