# Start With No Gun

This is a faithful data-only conversion of **No Gun** by the.apothem.

Select **Start With No Gun** from the game-mode option. Combat stages no longer grant the normal starter pistol, and the player receives exactly `$500` to purchase equipment. Pickups, vendors, inventory, and every other Standard rule remain unchanged.

The legacy replacement `Assembly-CSharp.dll` is neither required nor included.
