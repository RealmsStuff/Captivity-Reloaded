# Simple Nerf Gun conversion

This is a data-only conversion of the legacy **Captivity: Nerf Gun** replacement by `@SomeScrub`. The three PNGs were recovered from the supplied legacy `sharedassets0.assets`; no executable code or Unity bundle replacement is required.

To enable it in an editor checkout, copy this entire `simple-nerf-gun` directory into the project-level `Mods` directory. For a built game, copy it into `Mods` beside the game executable.
