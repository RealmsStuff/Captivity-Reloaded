# Clothing + Shack Overhaul

Faithful cross-platform `.capmod` rules conversion of the legacy DLL. It preserves the clothing-loss pressure plus the timed Tank Grabber, Boomer Zombie, and Pink Hound promotions without loading managed code. The old DLL itself is intentionally not distributed.

Select **Clothing + Shack Overhaul** as the active rule profile after installing the package.
