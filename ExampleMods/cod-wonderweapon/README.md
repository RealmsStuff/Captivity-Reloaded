# CoD Wonderweapon

This is a faithful data-only conversion of the supplied legacy **CoD Wonderweapon** archive.

It replaces the Core Schockgewehr inventory/body sprite with the recovered wonder-weapon artwork. The existing Schockgewehr remains the same weapon: FER placement, keycard unlock, Android interaction, ammunition, firing behavior, and statistics are unchanged.

The old whole-archive `sharedassets0.assets` replacement is neither required nor included. The original archive did not identify its author; provenance must be resolved before public catalog distribution.
