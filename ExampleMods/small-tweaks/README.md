# Small Tweaks conversion

This pack preserves all nine sprite changes found in the supplied legacy **Small Tweaks** archive: the four player chest palettes, the brown ponytail, the additional `Chest_7` character sprite used by shipped stages, and all three shared muzzle flashes.

It changes artwork only. It does not add weapons, clothing, missions, stats, or other gameplay that was not present in the original archive.
