# Tweaked FER

Faithful `.capmod` source conversion of the legacy **Tweaked FER** archive.

The archive is a visual retouch rather than a stage or gameplay replacement. It contains 20 deliberate FER character-part edits and ten deliberate blood/gore effect edits. This package therefore patches the shipped named sprites in place, preserving FER's AI navigation, scripted sequences, interactions, lighting, doors, and save identity. The same named slots can also reach retained Core objects used by the portable Tiled FER stage.

All 30 changed records differ materially from the v1.0.5b baseline; no compression-only records were excluded. The archive has no author or version text, so its author is recorded as the legacy mod author rather than inventing attribution.
