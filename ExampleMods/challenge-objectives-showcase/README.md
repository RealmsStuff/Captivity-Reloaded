# Challenge Objective Showcase

Copy this folder into the game's `Mods` directory to test five challenge patterns:

* `lamarr-remix` inherits the complete specialized Lamarr behavior.
* `pistol-specialist` combines weapon and enemy filters.
* `untouchable` counts waves completed without damage.
* `field-medic` counts successful uses of one usable item.
* `three-part-trial` demonstrates ordered, same-run steps plus currency, item, weapon, and persistent content rewards.

The rewards deliberately reference existing Core content so the example contains no art assets. Change the reward IDs to content from your own pack when using these as templates.
