# Raygun Revolver

This is a faithful data-only conversion of the supplied legacy **Raygun Revolver** archive.

It replaces the equipped `base` sprite of the Core `.44 Revolver` with the recovered raygun artwork. The revolver retains its original inventory identity, price, ammunition, damage, reload animation, unlock state, and firing behavior.

The old whole-archive `sharedassets0.assets` replacement is neither required nor included. The original archive did not identify its author; provenance must be resolved before public catalog distribution.
