# Goblin Slayer Armor

This is a faithful data-only conversion of the legacy **Captivity: Goblin Slayer Armor** by `@Datz`.

The original mod replaced the existing Knight armor artwork; it did not add a second set, new missions, or new statistics. This pack therefore patches the four Core Knight garments directly:

- Knight Helmet
- Knight Breast Plate
- Knight Pants
- Knight Boots

The armor retains its normal Jungle unlock, wardrobe identity, categories, durability, connected-piece behavior, and gameplay statistics. Only its icon and equipped sprites change.

All thirteen recovered PNGs are packaged explicitly. The old whole-archive `sharedassets0.assets` replacement is neither required nor included.
