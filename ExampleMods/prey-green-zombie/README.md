# Prey Green Zombie conversion

This is a data-only enemy variant recovered from the user-supplied legacy **Prey Mod (Bunny Girls)** by `@Draco66Electro`. It demonstrates the first `coreRigAtlas` workflow: one PNG atlas and one enemy JSON file extend `core:enemy/zombie-1` while reusing its AI, animation rig, colliders and gameplay behaviour. Its explicit spawn setting also adds it to the Core zombie's existing stage spawners.

The source overhaul replaced assets inside Unity's `sharedassets0.assets`. The pieces in this atlas were matched to the existing zombie rig using their original sprite pivots and then packed into one portable texture. This example does not include or execute legacy code.

The pack also contains `original-green-stalker`, an experimental enemy built without a Core enemy prefab. Select **Original Enemy Lab** to test its complete 18-bone skeleton, hit zones, procedural clips, melee, hitscan, physical-projectile, area, grab, and multi-stage attacks, ground-chase AI, and configurable finisher QTE. Its `move` clip is loaded from the separate normalized `enemy-animation/stalker-move` document and exercises transform, atlas-sprite, color, and sorting tracks. The first finisher phase loads `player-animation/stalker-restraint` and uses the `alternate` QTE; the second loads `player-animation/stalker-sqoid-presentation`, switches to the `tap` QTE, and includes a Squoid-derived particle trigger. The projectile intentionally reuses the atlas's hand region as a conspicuous temporary test sprite. The QTE reuses Captivity's struggle meter and supports keyboard, controller, and mobile inputs. You can also reference `draco66electro.prey-green-zombie:enemy/original-green-stalker` from another stage spawner.

`mixed-specimens-challenge.json` demonstrates a same-run challenge whose allowlists combine this original Green Stalker with vanilla Zombie I. Enemy filters also work with weapon kills, rape events, orgasms, and impregnations; an empty list means any enemy.

Example packs are disabled by default. To enable this one in an editor checkout, copy this entire `prey-green-zombie` directory into the project-level `Mods` directory. For a built game, copy it into `Mods` beside the game executable.
