# CoD Perk Machine conversion

This data-only compatibility test replaces the Core usable-vendor world sprite with the supplied legacy CoD Perk Machine artwork. It deliberately preserves the original `Vendor` prefab, catalog, controller navigation, purchase rules, and UI.

Copy this pack into `Mods`, enable it, then enter any stage containing an item/medicine vendor. The replacement machine should still open the normal store and sell both Core and modded usable items.
