# Zombie I template runtime test

This data-only example packages the exact atlas generated by `ModSDK/EnemyTemplates/Zombie1/build-zombie-template.js`. It registers a separate enemy extending `core:enemy/zombie-1`; it does not replace the Core Zombie I.

The test variant deliberately has 80 health, a bounty of 1, and 85% animation speed. It also demonstrates thorns, brief ragdoll on a successful hit, an obvious red death-explosion ring, one Core Zombie I spawned on death, and strong periodic speed bursts. Its artwork should look identical to Zombie I until a template layer is edited.

Example packs are disabled by default. Copy this entire `zombie-1-template` directory into the project-level `Mods` directory, restart the game, and enable it in the Mods panel. Because `inheritTemplateSpawners` is enabled, the variant joins every spawner that already contains Zombie I.

After changing the SDK artwork, export the edited atlas over `assets/enemies/zombie-1-template.png`, restart, and confirm the edited parts remain attached throughout idle, walking, attacking, damage, and death animations.
