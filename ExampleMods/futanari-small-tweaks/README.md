# Futanari + Small Tweaks

Faithful `.capmod` source conversion of the legacy **Futanari + Small Tweaks** archive.

The archive contains the same nine deliberate edits as `legacy.small-tweaks`, plus five deliberate replacements of the four player butt palette sprites and the separately placed `Butt_5` sprite. The five replacement images retain the original archive's full 32x32 canvas, pivot, and pixels-per-unit behavior.

To avoid duplicating identical content, this package depends on `legacy.small-tweaks` and contributes only those five unique sprite replacements. Six additional records differed by only one or two channel values because the archive had been recompressed; those are not authored changes and are intentionally excluded.

The source archive contains no author or version text, so its author is recorded as the legacy mod author rather than inventing attribution.
