# Survival Sprint

Copy this folder into `Mods`, enable it, and choose **Survival Sprint** from **Options > Game mode**.

It demonstrates a ten-wave victory goal, a 30-minute and 50-hit loss limit, kill/wave scoring with a damage penalty, shorter intermissions, faster and denser spawning, starting money, increased bounties, a higher ammo-drop chance, and separate player/gun damage multipliers.
